DSM learned score

step 0 · loss —
clean x₀ noisy x̃ + conditional target → MLP 学到的 score → 解析 noisy score（默认隐藏）
一条监督信号：紫点是 x̃，白点是它对应的 x₀。连线方向就是 conditional score (x₀-x̃)/σₙ²。
为什么杂乱仍能学习：同一个 noisy 位置可能对应不同 clean 样本。平方损失让 MLP 学到这些条件箭头的平均值，它恰好等于 ∇ log pσₙ(x̃)。
注意目标被平滑：固定非零 σₙ 时，DSM 学到的是加噪后 density 的 score，不是原始 p₀ 的 score。DDPM 会进一步学习所有噪声时间。
自己验证：先看青色箭头从随机状态逐渐成形，再暂停 DSM，点击“揭晓解析答案”；橙色和青色越重合，学习越准确。
改变参数会重训：调整峰权重、峰宽或噪声后模型自动清零，因为目标分布已经变化。
下一步：把单一 σₙ 换成时间轴 t，让一个网络同时预测 s(xₜ,t)，就进入 DDPM 的训练视角。

一条 DSM 训练数据是怎样产生的？

手动单步 · 不会自动前进
1 · 从数据分布采样 clean x₀
2 · 独立采样 ε ~ N(0, I)
3 · 前向加噪：xₜ = x₀ + σₙε
4 · 构造 label：(x₀ − xₜ) / σₙ²
5 · 比较 MLP 输出并形成 squared loss
按“开始”生成一条具体训练数据。
